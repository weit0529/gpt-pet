# 隐私与安全检查

检查日期：2026-10-08。范围：本仓库待提交文件、安装脚本、打包脚本及本地 Release ZIP。此检查为静态审查和本地验证，不是第三方安全认证。

## 隐私整理

- 采用文件清单复制，仅保留最终安装素材、离线预览、展示素材、公开文档和构建脚本。
- 未包含源项目的参考图、示例角色、生成提示词、原始条带、历史备份或内部适配记录。
- 已扫描公开文本中的本机用户名、绝对私人路径、邮箱、API Key、访问令牌和私钥特征；未发现需公开的个人信息或凭据。
- 已检查展示图片内容及图片 EXIF/XMP/ICC 注释等元数据；未发现账号信息、聊天记录或私人路径。
- 初始 Git 提交使用项目公共身份 `GPT Pet contributors <contributors@example.invalid>`，不使用机器上的个人 Git 身份。

## 执行与网络行为

- 清单和 WebP 为静态资源。预览只有本地 HTML、CSS、JavaScript 和相对资源路径，没有外部脚本、字体、遥测、自动网络请求、Cookie 或浏览器持久化逻辑。
- 安装脚本在创建安装目录前检查清单、WebP 格式和尺寸，固定复制 `pet.json` 和 `spritesheet.webp`；清单不能控制目标文件路径。
- 重复安装先备份旧目录，安装后比较 SHA-256；拒绝直接安装目录及旧宠物内容中的符号链接/目录联接。不请求管理员权限，也不调用网络下载、执行远程代码或改变执行策略。
- 自定义 `CodexHome` 是用户指定的写入位置，默认只使用本地 Codex 数据目录。祖先目录的链接和并发文件替换不属于脚本能够完整防护的范围，安装时应使用可信的本地目录。
- Release 构建只读取明确清单里的文件，生成固定元数据 ZIP 和 SHA-256 校验文件。缓存、凭据、Git 历史及本机路径不进入 ZIP。
- 本仓库没有第三方运行依赖或自动发布工作流。

## 本地验证

- 完整解码最终图集，检查尺寸、透明通道、73 个有效格、15 个全透明空格和帧边界。
- 比较展示动画每帧与最终图集对应格的透明通道和可见像素，确认展示素材对应本次发布。
- 对临时目录执行首次安装与覆盖安装，检查复制哈希及旧文件备份；无效清单与错误图集均在写入前被拒绝。
- 静态审查链接目录拒绝逻辑。本地环境禁止创建目录联接，因此未执行该分支的实际联接测试。
- 连续构建两次，比较 ZIP 哈希；检查 ZIP 文件清单、CRC 和每个文件的内部 SHA-256。
- 检查 README 与预览的本地资源链接、Python 语法和 PowerShell 语法。
- 源项目在整理前后逐文件比较 SHA-256，确认文件清单和内容均未改变。

## 限制

SHA-256 可验证内容一致性，不提供发布者签名；请从可信仓库下载。宿主应用自身权限、联网、遥测和数据处理不属于本包审查范围。本次没有修改当前已安装的宠物，也没有对真实 Codex 任务事件做端到端验证。图片来源与第三方权利不能通过技术扫描确认；MIT 许可不授予第三方商标或其他第三方权利。
